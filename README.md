# Valorant Project

A fan-made website dedicated to the popular tactical first-person shooter game, Valorant. This project showcases various aspects of the game, including agent roles, gameplay mechanics, and an immersive user experience.

## Description

Valorant Project is a static website built to celebrate and inform about Valorant. It features sections on the game's core elements like 5v5 tactical gameplay, agent categories (Duelists, Sentinels, Initiators, Controllers), and an introductory video. The site uses smooth scrolling and interactive carousels to provide an engaging experience.

## Features

- **Game Overview**: Highlights key aspects like 5v5 matches, tactical strategies, and first-person shooting.
- **Agent Showcase**: Displays different agent roles with images and descriptions.
- **Interactive Elements**: Includes a video player and swiper-based carousels for dynamic content.
- **Responsive Design**: Optimized for various screen sizes.
- **Smooth Scrolling**: Implemented using Locomotive Scroll for a fluid navigation experience.

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and dynamic behavior.
- **Locomotive Scroll**: For smooth scrolling effects.
- **Swiper**: For carousel functionality.

## Installation

1. Clone or download the repository to your local machine.
2. Navigate to the `Valorantproject/ValorantProject` directory.
3. Open `valo.html` in your preferred web browser to view the site.

No additional dependencies or server setup is required, as this is a static website.

## Usage

- Open `valo.html` in a browser.
- Navigate through the sections using the menu or scrolling.
- Explore agent categories and watch the introductory video.
